# 周文王先天易卦占卜｜設計規格

## 目標

在隴善堂官方網站建立「周文王先天易卦占卜」功能。使用者以三個籤筒依序抽取百位、十位、個位，各籤筒包含 1～8 共 8 支籤，三次結果組成三位卦碼（111～888），再由卦碼查出對應卦名與卦辭。

## 已確認的核心流程

1. 頁面標題：周文王先天易卦。
2. 畫面中央呈現三個傳統籤筒：百位、十位、個位。
3. 每個籤筒內邏輯上各有 1～8 共 8 支籤。
4. 使用者依序抽籤：百位 → 十位 → 個位。
5. 每次抽籤由系統在 1～8 中隨機抽出一個數字，不提供直接點選數字。
6. 三個數字組合成卦碼，例如 3、7、8 → 378。
7. 系統以卦碼查詢卦辭資料庫。
8. 查詢成功後顯示卦碼、卦名、卦辭。
9. 提供「重新占卦」功能，清除本次三個抽籤結果後重新開始。

## 動畫規格

每一個籤筒的抽籤流程：

1. 使用者按下該籤筒的「抽籤」按鈕。
2. 籤筒左右輕微晃動約 1～1.5 秒。
3. 筒內籤支同步上下錯動，營造搖籤感。
4. 隨機選中的籤支向上彈出。
5. 籤支停止後顯示抽中的數字。
6. 完成百位後才開放十位；完成十位後才開放個位。
7. 三支籤全部完成後，三個數字以短暫聚合動畫組成完整三位卦碼。
8. 卦辭結果區淡入顯示。

動畫風格採傳統、莊重，不使用遊戲化爆炸、轉盤或過度炫光效果。支援 `prefers-reduced-motion`，使用者若開啟減少動態效果，則縮短或取消位移動畫但保留功能。

## 視覺方向

- 沿用隴善堂官網既有紅、金、米色系與 `public/styles.css` 的整體語彙。
- 籤筒採木質／深紅傳統造型；籤支採竹木色，文字以紅或深色呈現。
- 桌機版三個籤筒橫向排列。
- 手機版三個籤筒可改為單欄垂直排列，確保按鈕與抽出籤支尺寸足夠。
- 結果區要清楚突出「卦碼」與「卦辭」，避免過度裝飾影響閱讀。

## 資料模型

卦辭資料以三位字串卦碼作為唯一鍵。資料來源以已整理完成的原始易經資料為準，不自行補寫或改寫卦辭。

建議格式：

```json
{
  "111": {
    "name": "乾",
    "text": "天雨問晴天必雨，天晴問雨主天晴，若要雨零看亥子，晴多雨少數分明。"
  }
}
```

三位卦碼每一位僅允許 1～8，因此完整空間為 8 × 8 × 8 = 512 組。資料載入後應檢查是否正好涵蓋 512 組合法卦碼；若某碼缺漏或重複，應在資料建置階段修正，不在前端用臆測內容補齊。

## 程式結構

- `public/pages/divination.html`：頁面結構、說明、三籤筒與結果容器。
- `public/divination.css`：籤筒、籤支、動畫與響應式樣式。
- `public/divination.js`：抽籤狀態機、亂數、依序解鎖、三碼組合、資料查詢、重置。
- `public/data/divination.json`：111～888 卦碼對應卦名與卦辭。

不把占卜資料硬寫在 HTML 中，避免未來校對卦辭時必須修改頁面程式。

## 抽籤狀態與規則

頁面狀態包含：

- `hundreds`: `null | 1..8`
- `tens`: `null | 1..8`
- `ones`: `null | 1..8`
- `isDrawing`: 是否正在播放抽籤動畫

規則：

- 百位尚未完成時，十位與個位按鈕不可操作。
- 十位尚未完成時，個位不可操作。
- 動畫進行中禁止重複觸發，避免一次產生兩個結果。
- 每一筒只抽一次，除非使用者按「重新占卦」。
- 亂數範圍固定為整數 1～8。
- 三位完成後才查詢資料並顯示結果。

## 錯誤處理

若三碼完成但找不到對應資料，不顯示自創卦辭；顯示「此卦資料尚待校對，請重新占卦或稍後再試」並在瀏覽器主控台記錄卦碼，方便維護者檢查資料。

若 `divination.json` 載入失敗，抽籤功能保持停用並顯示「卦辭資料暫時無法載入」。

## 可及性

- 每個抽籤按鈕使用真正的 `<button>`。
- 籤筒區域提供清楚文字標籤：百位籤筒、十位籤筒、個位籤筒。
- 抽中結果與最終卦碼使用 `aria-live` 告知螢幕閱讀器。
- 鍵盤操作可完成整套流程。

## 第一版範圍

第一版只完成三籤筒取三碼、動畫、卦碼組合與卦辭查詢，不加入擲筊、AI 解籤、會員紀錄、分享結果、後台編輯或占卜歷史。

## 驗收條件

- 桌機與手機都能正常顯示三個籤筒。
- 每筒亂數只可能產生 1～8。
- 抽籤順序固定為百位、十位、個位。
- 抽籤期間不能重複點擊造成狀態錯亂。
- 三碼能正確組合，例如 1、1、1 → `111`。
- `111` 能對應資料中的「乾」與正確卦辭。
- 重新占卦可完整清除狀態。
- 動畫在手機與桌機皆可執行，並尊重 reduced-motion 設定。
